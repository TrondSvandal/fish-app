## Getting Started

### Requirements

See `requirements.txt` for Python dependencies.

### Installation

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python app.py
```

## Usage

Visit the web application in your browser to identify fish species.
